# trilium-mcp

MCP server (stdio, Docker) that lets Claude read and organise a [TriliumNext](https://github.com/TriliumNext/Trilium)
knowledge base through its ETAPI, with first-class support for **Note Map** and **Relation Map** notes.
Developed against Trilium `v0.106.0`.

## Setup

1. In Trilium: *Options → ETAPI → Create new ETAPI token*.
2. Build the image:

   ```bash
   docker build -t trilium-mcp:0.1.1 .
   ```

3. Add it to `claude_desktop_config.json` (same pattern as any stdio Docker MCP):

   ```json
   {
     "mcpServers": {
       "trilium": {
         "command": "docker",
         "args": ["run", "--rm", "-i",
                  "-e", "TRILIUM_URL", "-e", "TRILIUM_ETAPI_TOKEN", "-e", "TRILIUM_VERIFY_TLS",
                  "-v", "trilium-mcp-backups:/tmp/trilium-mcp-backups",
                  "trilium-mcp:0.1.1"],
         "env": {
           "TRILIUM_URL": "https://trilium.example.com",
           "TRILIUM_ETAPI_TOKEN": "<token>",
           "TRILIUM_VERIFY_TLS": "true"
         }
       }
     }
   }
   ```

   `TRILIUM_VERIFY_TLS=false` is for self-signed certificates. If Trilium runs on the same Docker host without a
   reverse proxy, use a URL reachable from the container (e.g. `http://host.docker.internal:8080`).

## How to get good-looking maps

A **Note Map** is generated by Trilium from the tree, **relations** and internal links; it cannot be drawn by hand.
So the recipe is: structure → connect → style → map.

1. `trilium_create_structure` builds a nested outline with labels, icons, colours and relations (`@ref` lets nodes point
   to each other before their ids exist).
2. `trilium_set_relation` / `[[noteId|text]]` links add the edges.
3. `trilium_style_note` sets `iconClass` / `color`.
4. `trilium_create_note_map` creates the map (`mapRootNoteId`, `mapIncludeRelation`, `mapExcludeRelation`).

For a hand-placed canvas use `trilium_create_relation_map` (grid / circle / row / column layouts).

## Tools

| Area | Tools |
|---|---|
| Read | `trilium_app_info`, `trilium_search_notes`, `trilium_get_note`, `trilium_get_tree`, `trilium_get_backlinks_and_relations` |
| Write | `trilium_create_note`, `trilium_update_note`, `trilium_set_note_content`, `trilium_append_note_content`, `trilium_delete_note`, `trilium_clone_note`, `trilium_move_note`, `trilium_reorder_children`, `trilium_create_structure` |
| Attributes | `trilium_set_label`, `trilium_set_relation`, `trilium_delete_attribute`, `trilium_style_note` |
| Maps | `trilium_create_note_map`, `trilium_create_relation_map`, `trilium_update_relation_map` |
| Journal / history | `trilium_get_day_note`, `trilium_get_inbox`, `trilium_recent_changes`, `trilium_create_revision`, `trilium_list_revisions` |
| Escape hatch | `trilium_call_endpoint` |

Text notes are Markdown by default and converted to Trilium's HTML. Deleting a note or overwriting its content writes a
JSON snapshot to `/tmp/trilium-mcp-backups` (mounted as a volume above) and returns the path.

## Development

```bash
docker build -t trilium-mcp:dev . && docker run --rm --entrypoint sh -v "$PWD:/src" -w /src trilium-mcp:dev \
  -c "pip install -q pytest && PYTHONPATH=src pytest -q"
```
